Medallion layers

LayerWhat it holdsWritten by
raw Append-only source events, exactly as received Flink SQL · ga4_batch_ingest.py
staging Cleaned, typed, deduplicated; GA4 events also rolled up into sessions staging_batch.py
semantic Entity resolution — one unified customer across all five sources entity_backfill.py
core Unified business objects built on the resolved entities core_views.py
analytics Aggregated metrics: customers, orders, payments, campaigns, GA4 engagement analytics_incremental.py
marts Dashboard-ready tables — customer 360, sales, campaigns, GA4 engagement marts_incremental.py
